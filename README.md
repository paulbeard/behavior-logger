# behavior-logger
This is form-based student behavior logger for classroom teachers, special education teachers and staff to create standardized data for later analysis. 

This grew out of a paper form that was input into Microsoft Forms, period by period, day by day — for what turned into 1,066 periods across 167 days. To say it was unwieldy strains the meaning of the word. Partway through the year, I turned the data (stored in Excel, as Forms does) over to Claude.ai, and from that a redesigned paper collection form and these HTML pages were developed.

Note: this is not what I actually used — it's backfilled from the process used to report a full year of student data, in hopes of making it simpler the next time around: create a form for the student, fill out the data, rinse, repeat. You end up with consistent language on timestamped entries that you can run reports against. See the reporting/ directory for the report generator.

This is not supported, and I am not taking feature requests — think of it more as a toolbox than a tool. Use it as-is, or customize it to your needs. The documentation and included code/algorithm are intended to help with IT compliance review and deployment, not ongoing support.
