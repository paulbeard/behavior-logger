# behavior-logger
This is form-based student behavior logger for classroom teachers, special education teachers and staff to create standardized data for later analysis. 

This grew out of a paper form that was input into Microsoft Forms, period by period, day by day for what turned into 1,066 periods across 167 days. To say it was unweildy strains the meaning of that word. Partway through the year I turned the data (stored in Excel as Forms does) to Claude.ai and from the redesigned paper collection form and HTML pages were developed. 

NB: this is what what I used, it is backfilled from the process that was used to report a full year of student data, in hopes of making it simpler: create a form for the student, fill out the data, rinse, repeat. You end up with consistent language on timestamped entries that you can run reporta against. See the reporting directory for details. 

This is not supported and I am not taking feature requests: think of it more as a toolbox than a tool. You can use it as is but it can be customized to your needs. The documentation and supplied code/algorithm is intended to help with IT compliance and deployment support.
